# ✈️ Airline Analytics Dashboard

A Power BI project created to explore airline flight and passenger data through
interactive dashboards and visualizations.

## 📌 About the Project

This project focuses on analyzing flight operations, passenger demographics,
airport networks, and flight patterns.

The dashboard was built in Power BI using a combination of data modeling,
DAX measures, filters, and interactive visuals.

## 🗂️ Data Model

The Power BI model contains four main tables:

- `FactFlights`
- `DimPassenger`
- `DimAirport`
- `DimDate`

The fact and dimension tables are connected through relationships to support
filtering and analysis across the dashboard.
